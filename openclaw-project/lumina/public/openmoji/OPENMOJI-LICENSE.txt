OpenMoji emoji graphics
=======================

Emoji graphics by OpenMoji (https://openmoji.org), licensed under CC BY-SA 4.0 (https://creativecommons.org/licenses/by-sa/4.0/).

The folder "svg/" contains 4,495 OpenMoji colour SVG files, named by Unicode codepoints in uppercase hex joined with hyphens
(for example 1F600.svg and 1F9D1-1F3FD-200D-1F373.svg).

THE FILES ARE UNMODIFIED. They are byte-for-byte the files from the original "openmoji-svg-color.zip" distribution:
  zip SHA-256: 59b0cd9f6fe033818fc02585cea42bea9fba5d68a4d3a3639bfe5d5cc3805689   (4,495 files)
Nothing was edited, recoloured, resized, optimised or converted. To check: unzip that archive into an empty folder and run
"diff -r <that folder> svg/"; there should be no differences.

Derived data (not artwork)
  ../../src/lib/openmoji/files.json and index.json are generated by scripts/build-openmoji-index.mjs from this folder's file names and
  from OpenMoji's openmoji.json (https://github.com/hfg-gmuend/openmoji, data/openmoji.json; SHA-256
  b3a07c1c41b6b500423d01fb91c5d41e9c9337a53d217af20a3539d7df8438e4, latest entry dated 2026-08-06): names, keywords and groups for search.
